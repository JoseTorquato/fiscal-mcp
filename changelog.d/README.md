# Fragmentos de changelog

Um arquivo por PR, criado com `PYTHONUTF8=1 scriv create`. O PR de release junta
todos no `CHANGELOG.md` com `scriv collect`. O formato (quatro campos por item)
e o fluxo estão no [CONTRIBUTING.md](../CONTRIBUTING.md#changelog).

Este README e o `_modelo.md.j2` não são coletados.
