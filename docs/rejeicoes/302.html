Rejeição 302

Uso denegado — irregularidade fiscal do destinatário.

irreversível — o documento não vira autorizado depoisNF-e · SEFAZ
01.

O que aconteceu

Mesma mecânica da 301, com o bloqueio do outro lado: quem está irregular é o destinatário. Do ponto de vista do código não há o que corrigir no XML — o que existe é uma decisão de negócio sobre emitir ou não para aquele destinatário enquanto a situação não se resolve.

02.

Por que não há XML para corrigir

Esta rejeição não tem XML errado para mostrar

Não há XML errado para mostrar. Se o caso é frequente na sua operação, o que evita a denegação é conferir a situação cadastral antes de emitir — consulta de cadastro é serviço da SEFAZ, e sai mais barato que uma chave queimada.

03.

O que fazer

Confira a situação cadastral do destinatário. Nota denegada fica registrada e não pode ser cancelada nem reemitida para o mesmo destinatário sem regularização.

04.

Reproduzir sem transmitir

Tudo aqui roda na sua máquina, sem certificado e sem enviar nada para lugar nenhum.

# o que a SEFAZ quis dizer
fiscal-mcp rejeicao 302

05.

A redação exata varia

A mensagem que chega da SEFAZ muda de UF para UF e de versão para versão do Manual de Orientação do Contribuinte — o que não muda é o código. O texto acima é o significado consolidado no catálogo do fiscal-mcp, não a transcrição literal de uma resposta.

Se a sua veio diferente, ou se o campo que resolveu foi outro, abra uma issue — o catálogo é um YAML de umas poucas linhas, e é assim que ele fica melhor.
